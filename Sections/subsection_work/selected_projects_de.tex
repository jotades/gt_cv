{OmniTrack: IoT-based Multimodal Navigation System \href{https://www.frontiersin.org/journals/communications-and-networks/articles/10.3389/frcmn.2026.1829998/abstract}{\color{blue}/Frontiers}}
{}
{}
{}
{
\begin{itemize}
\item Built the data pipeline end to end: UWB ranging and IMU time series from wearable ESP32 tags (micro-ROS), position estimation in ROS 2, and session logging in MongoDB.
\item Developed OmniAnalytics, a Python/FastAPI backend (pandas, NumPy) with a React dashboard that turns raw session recordings from 16 blind participants into trial metrics: route similarity (DTW, Fr\'echet distance), speed, and target discovery.
\item Kept data traceable: corrections, exclusions, and annotations are stored separately, so raw recordings are never modified.
\end{itemize}
\vspace{+0.2em}
\texttt{Python • pandas • FastAPI • MongoDB • React • ROS2 • ESP32 • UWB • IMU}

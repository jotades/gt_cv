{}
{}

{
\begin{itemize}
\item Built the data path end to end: UWB ranging and IMU time series from wearable ESP32 tags, position estimation in ROS 2, and session logging in MongoDB.
\item Designed OmniAnalytics, a data tool that turns raw session recordings from 16 blind participants into trial metrics: route similarity (DTW, Fr\'echet distance), speed and target discovery.
\item Kept data traceable: corrections, exclusions and annotations are stored separately, so raw recordings are never modified.
\end{itemize}
